# RENA Historical Archive

This directory stores historical, superseded, and legacy artifacts from earlier developmental phases of RENA (v1–v2).

## Contents

- `root_docs/`: Superseded release notes, early feature lists (`APP_FEATURES_V17.md`, `V22_RELEASE.md`), and historical implementation logs.
- `root_scripts/`: Legacy loose execution scripts from earlier prototypes (`run_rena_v2.py`, `run_echo_experiment.py`, etc.). Current pipeline execution is organized under `core/`, `backend/`, and `scripts/`.
- `legacy_results/`: Simulation and benchmark results generated during early algorithmic calibration before independent audit reviews.
- `legacy_backups/`: Historical directory backups.

> [!NOTE]
> None of the files in this archive are cited as empirical proof in the current RENA paper or claims ledger. All active empirical evidence is indexed in `results/EVIDENCE_INDEX.md`.
